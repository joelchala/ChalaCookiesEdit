ChalaCookiesEdit

Suite Chala · Escudo Cibernético · Manifest V3

1. Gestión CRUD y reglas MV3

Crea, edita, duplica o elimina cookies en la pestaña activa:

  • Host-only vs Subdominios: deja el campo dominio vacío o con el host exacto para cookies host-only; inicia con punto (.ejemplo.com) para compartir con subdominios.
  • SameSite=None: la extensión fuerza automáticamente Secure = true y URL https:// antes de invocar chrome.cookies.set.

2. Inspector JWT 100 % local

Al expandir o editar cualquier cookie con formato header.payload.signature, ChalaCookiesEdit decodifica Base64URL en memoria local y muestra el Header, Payload y el estado de vigencia (exp / nbf).

3. Bloqueo persistente

Marca cualquier cookie como Bloqueada (guardada por dominio + nombre en chrome.storage.local). El Service Worker escucha chrome.cookies.onChanged y la elimina automáticamente si el sitio intenta regenerarla.

4. Importar y Exportar

Exporta en JSON o formato Netscape cookies.txt (compatible con curl y yt-dlp, incluyendo el prefijo #HttpOnly_) o importa pegando texto o cargando un archivo local.

1. Full CRUD & MV3 Rules

Create, edit, duplicate, or delete cookies for the active tab:

  • Host-only vs Subdomains: leave the domain field empty or equal to the exact host for host-only cookies; start with a dot (.example.com) to include subdomains.
  • SameSite=None: automatically enforces Secure = true and an https:// URL before calling chrome.cookies.set.

2. 100% Local JWT Inspector

Expanding or editing any cookie formatted as header.payload.signature automatically decodes Base64URL in local memory and displays formatted Header, Payload, and expiration status (exp / nbf).

3. Persistent Cookie Blocking

Mark any cookie as Blocked (stored by domain + name in chrome.storage.local). The Service Worker listens to chrome.cookies.onChanged and removes it immediately whenever the site attempts to recreate it.

4. Import & Export

Export to JSON or standard Netscape cookies.txt (ready for curl and yt-dlp, including #HttpOnly_), or import by pasting text or uploading a file.

Local Build & Verification (Node.js >= 22)

npm run icons
npm test
